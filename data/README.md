# data

Inputs for the solver. Everything under `processed/` is generated by
[`dataprep/`](../dataprep/README.md).

Two **sample cities are committed: Bath (hilly) and Cambridge (flat)**, on a **5 km × 5 km
grid**. That's enough to build and run the solver straight after cloning. Every other city's
data is git-ignored and can be regenerated with `dataprep/`.

```
data/
├── raw/
│   ├── solomon/        Original Solomon benchmark CSVs (16 instances)
│   └── cities.csv      City table: centre lat/lon, size, hilliness, population
├── processed/
│   ├── instances/      <City>_<scale>_<benchmark>.csv         (sample cities committed)
│   ├── short_paths/    <benchmark>_short_paths.txt           (all committed; city-independent)
│   ├── edge_profiles/  <City>_<scale>_<benchmark>.csv         (sample cities committed)
│   ├── edge_samples/   per-edge elevation samples (JSON)      (ignored)
│   └── plots/          MST/elevation plots                    (ignored)
├── weather/            Hourly weather per city                (sample cities committed)
│   └── open-meteo/<year>/<City>-weather-<year>.csv   2022–2025
└── dem/                Copernicus DEM tile cache              (ignored; downloaded on demand)
```

## Sources

| Dataset | Source |
|---|---|
| Solomon VRPTW benchmarks | Solomon (1987), *Algorithms for the vehicle routing and scheduling problems with time window constraints* |
| Elevation | [Copernicus GLO-30 DEM](https://registry.opendata.aws/copernicus-dem/), via the public AWS bucket |
| Weather | [Open-Meteo](https://open-meteo.com/) historical API |

### Cities

Aberystwyth, Bath, Belfast, Birmingham, Bristol, Cambridge, Cardiff, Carlisle, Chichester,
Derry, Glasgow, Inverness, Lancaster, Leeds, Liverpool, London, Newcastle, Plymouth,
Southampton, Wrexham.

## What gets committed

The root `.gitignore` ignores everything under `data/` by default, then allowlists:

- files with `Bath` or `Cambridge` in the **file name** (except scale-10 files, DEMs, edge
  samples and plots)
- `processed/short_paths/*.txt`, `raw/solomon/*.csv` and `raw/cities.csv`

To add another sample city, add a `!data/**/*<City>*` line. To check a path, run
`git check-ignore -v <path>`.
